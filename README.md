# نور القرآن

تطبيق قرآن كريم عربي بواجهة هاتف حديثة، يتضمن المصحف الكامل حسب صفحات مصحف المدينة، والتفسير الميسر، وتلاوات صوتية، وعلامات مرجعية، ومسبحة، ومتابعة الختمة.

## المميزات

- عرض الصفحة القرآنية كاملة حتى عندما تجمع نهاية سورة وبداية سورة أخرى.
- 604 صفحات مع انتقال مباشر بالسورة أو الصفحة أو رقم الآية.
- بحث شامل في نص القرآن.
- تفسير ميسر لكل آية.
- عشرة قراء، منهم مشاري العفاسي وماهر المعيقلي وعبدالرحمن السديس وعبدالباسط والحصري والحذيفي والشريم والعجمي والشاطري ومحمد أيوب.
- تنزيل التلاوات باختيار المستخدم، بدون تنزيلات إجبارية عند التشغيل.
- تنزيل القرآن والبحث المحلي كاملاً من الإعدادات، مع تحقق فعلي من التخزين واستكمال تلقائي عند الانقطاع.
- تنزيل التفسير الميسر كاملاً للعمل دون إنترنت.
- خط عثماني مبسط افتراضياً، وخيارات نسخ وشهرزاد ولطيف وأميري محفوظة داخل التطبيق.
- تحكم مستقل بحجم خط المصحف وتباعد السطور.
- حفظ آخر قراءة والعلامات والختمة محلياً.
- أوضاع فاتح وداكن وورقي.
- شعار وصورة تطبيق حقيقية بصيغة PNG، مع أيقونات واجهة موحدة وبدون رموز تعبيرية.
- نسخة ويب PWA ومشروع Android WebView آمن.

## APK

عند كل تحديث للفرع `main` يبدأ GitHub Actions ببناء APK تلقائياً. ستجد الملف في صفحة **Actions** داخل تشغيل workflow باسم `Noor-Al-Quran-APK`.

## تشغيل نسخة الويب

شغّل الملفات عبر خادم محلي أو GitHub Pages. فتح الملف مباشرة يعمل للقراءة عبر الإنترنت، لكن بعض خصائص التخزين والتنزيل تحتاج HTTPS.

## معلومات Android

- اسم الحزمة: `com.nooralquran.app`
- الإصدار: `1.2.0`
- الحد الأدنى: Android 7.0
- Target SDK: 35
- الصلاحيات: الإنترنت، الاهتزاز، ومنع إطفاء الشاشة أثناء المهام الطويلة.

## مصدر البيانات

يستخدم التطبيق واجهة Al Quran Cloud للنص القرآني والتفسير، مع مصادر صوتية بديلة عند تعذر أحد الخوادم.
